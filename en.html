Before you install

CK IPTV is a player. It does not provide any channels: you enter your own subscription (Xtream Codes, M3U playlist or stream link).

An activation code is required on first launch. It has 8 characters; its first digits give the duration:

  • 2… 2 days
  • 7… 7 days
  • 31… 1 month
  • 366… 1 year
  • 00… unlimited

Each code can only be used once. To get one, contact us.

Installation

  1. Install Downloader

    Search for the free Downloader app (orange icon) in the Play Store or the Amazon Appstore and install it.

  2. Allow the installation
    • Android TV / Google TV: Settings › Apps › Security & restrictions › Unknown sources, turn on Downloader.
    • Fire TV: Settings › My Fire TV › Developer options › Install unknown apps, turn on Downloader.
  3. Download

    Open Downloader and type the address of this page, then choose “Android TV” and Download.

  4. Install

    When the download is finished, choose Install. If Play Protect warns you: Install anyway (the app does not come from the Play Store). You can then delete the APK file.

  5. Activate

    Launch CK IPTV, enter the activation code (Internet required), then Activate. The Settings open: choose the source, enter the server, username and password of your subscription, then Save.

Without Downloader: copy the APK file to a USB stick and open it with a file manager (File Commander, X-plore) after allowing that file manager in step 2.

Common problems

“Invalid code” or “already used”

Check the 8 characters. A code can only be used once: ask for a new one.

“Licence expired”

Enter a new code: the activation screen comes back by itself. To add days before the end: Settings › Extend licence (2 + 2 days = 4 days).

“No connection” during activation

Activation needs Internet: check the Wi-Fi, then try again.

“Weak Internet connection”

The app has already lowered the picture quality if the channel allows it. Move closer to the router, use a cable, or choose a lower maximum quality in Settings › Display and language.

Username or password rejected

Check your subscription in the Settings, paying attention to capital letters.

“Too many connections”

The subscription is being used on another device: close the IPTV app there.

Category with a padlock

This is parental control. The default code is 0000; you can change it in the Settings.

“Video format not supported”

Choose another version (HD, SD). On PC, the V key opens the video in VLC.

The installation is blocked

Allow the app that opens the file (Downloader, Chrome, Files) to install unknown apps, as shown in the installation steps.
