Avant d'installer

CK IPTV est un lecteur. Il ne fournit aucune chaîne : vous entrez votre propre abonnement (Xtream Codes, liste M3U ou lien de flux).

Un code d'activation est demandé au premier démarrage. Il a 8 caractères ; son début donne la durée :

  • 2… 2 jours
  • 7… 7 jours
  • 31… 1 mois
  • 366… 1 an
  • 00… illimité

Chaque code ne sert qu'une fois. Pour en obtenir un, contactez-nous.

Installation

  1. Installer Downloader

    Cherchez l'appli gratuite Downloader (icône orange) dans le Play Store ou l'Appstore Amazon et installez-la.

  2. Autoriser l'installation
    • Android TV / Google TV : Paramètres › Applications › Sécurité et restrictions › Sources inconnues, activez Downloader.
    • Fire TV : Paramètres › Ma Fire TV › Options pour les développeurs › Applis de sources inconnues, activez Downloader.
  3. Télécharger

    Ouvrez Downloader et tapez l'adresse de cette page, puis choisissez « Android TV » et Télécharger.

  4. Installer

    À la fin du téléchargement, choisissez Installer. Si Play Protect avertit : Installer quand même (l'appli ne vient pas du Play Store). Vous pouvez ensuite supprimer le fichier APK.

  5. Activer

    Lancez CK IPTV, entrez le code d'activation (Internet nécessaire), puis Activer. Les Réglages s'ouvrent : choisissez la source, entrez le serveur, l'identifiant et le mot de passe de votre abonnement, puis Enregistrer.

Sans Downloader : copiez le fichier APK sur une clé USB et ouvrez-le avec un gestionnaire de fichiers (File Commander, X-plore) après avoir autorisé ce gestionnaire à l'étape 2.

  1. Télécharger

    Sur le téléphone, ouvrez cette page et touchez « Téléphone et tablette Android » › Télécharger. Si Chrome demande de confirmer, choisissez Télécharger quand même.

  2. Installer

    Ouvrez le fichier téléchargé. Android demande d'autoriser Chrome (ou Fichiers) à installer des applis inconnues : autorisez, revenez en arrière, puis Installer.

  3. Activer

    Entrez le code d'activation, puis votre abonnement dans les Réglages.

  1. Télécharger

    Choisissez À installer (raccourci sur le bureau) ou Sans installation (se lance directement, par exemple depuis une clé USB).

  2. Lancer

    Windows SmartScreen peut avertir, car l'appli n'est pas signée : Informations complémentaires › Exécuter quand même.

  3. Activer

    Entrez le code d'activation, puis votre abonnement dans les Réglages.

Conseillé : installez aussi VLC pour les films que le lecteur intégré ne sait pas lire (touche V pendant la lecture).

Mise à jour : téléchargez la nouvelle version et installez-la par-dessus l'ancienne. L'activation, les réglages et les favoris sont conservés.

Problèmes fréquents

« Code invalide » ou « déjà utilisé »

Vérifiez les 8 caractères. Un code ne sert qu'une fois : demandez-en un nouveau.

« Licence expirée »

Entrez un nouveau code : l'écran d'activation revient tout seul. Pour ajouter des jours avant la fin : Réglages › Prolonger la licence (2 + 2 jours = 4 jours).

« Pas de connexion » à l'activation

L'activation a besoin d'Internet : vérifiez le Wi-Fi, puis réessayez.

Identifiant ou mot de passe refusé

Vérifiez votre abonnement dans les Réglages, en respectant les majuscules.

« Trop de connexions »

L'abonnement est utilisé sur un autre appareil : fermez l'IPTV ailleurs.

Catégorie avec un cadenas

C'est le contrôle parental. Le code par défaut est 0000 ; vous pouvez le changer dans les Réglages.

« Format vidéo non pris en charge »

Choisissez une autre version (HD, SD). Sur PC, la touche V ouvre la vidéo dans VLC.

L'installation est bloquée

Autorisez l'appli qui ouvre le fichier (Downloader, Chrome, Fichiers) à installer des applis inconnues, comme indiqué dans l'installation.
